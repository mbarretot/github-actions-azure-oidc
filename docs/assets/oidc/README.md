# OIDC editorial assets

Original illustrations generated with the built-in ImageGen tool for this reference project. They are conceptual artwork, not official Azure or GitHub product logos or architecture diagrams. The repository's [MIT license](../../../LICENSE) applies to these project assets; no Microsoft or GitHub endorsement is implied.

## Art direction

Based on Plano's editorial design tokens: warm ivory `#faf8f3`, ink `#211f1c`, ochre `#8f5a12`, extended with vivid Azure blue, cyan and terracotta. Engraved architectural linework, restrained paper texture and clear negative space connect all three illustrations.

## Generation briefs

- **`logo.jpg`** — Square original architectural emblem: faceted Azure-blue cloud gateway, identity shield and folded deployment plane. Compact centered mark, ink engraving with cyan and ochre accents, no text or official vendor logos.
- **`deployment-hero.jpg`** — Wide architectural landscape connecting a developer workshop, a shield-shaped trust gateway and an Azure-blue cloud pavilion. A cyan ribbon represents temporary trust. Editorial ink linework, ivory paper, blue, cyan, terracotta and ochre; no labels or official logos.
- **`trust-journey.jpg`** — Wide isometric model of three pavilions: terracotta workshop, cyan identity checkpoint and Azure-blue cloud building. Token medallions cross bridges; an hourglass suggests temporary credentials. Same engraved editorial palette, no text or branding.

The source images were generated as PNG and converted to JPEG for repository delivery. See the README's Mermaid sequence for the actual protocol flow.
